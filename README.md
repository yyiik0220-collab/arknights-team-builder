# アークナイツ編成シミュレーター

手持ちオペレーター、育成状況、ステージ情報を照合し、編成候補と育成優先度を説明付きで提示する静的Webアプリです。ビルド不要で動く Vanilla JavaScript 製で、ユーザーデータは端末内の LocalStorage のみに保存し、外部へ送信しません。

## 機能一覧

- **オペレーター管理（手持ち管理）**: ★5/★6 を含む56体のマスターから所持状況・育成状況（レベル、昇進、スキル等）を登録・編集します。登録内容は LocalStorage に保存されます。
- **育成優先度の提案**: 編成需要と現在の育成状況を照合し、次に育てるべきオペレーターを優先度付きで提示します。重みは `data/scoring-config.json` に分離しています。
- **編成提案**: ステージ要件と手持ちから、編成候補をスコアと根拠付きで複数提示します。
- **シナジー検出**: 編成内のオペレーター間のシナジー（素質・スキル・陣営）を検出・スコアリングし、追加・入替候補を提案します。
- **素材計算**: 昇進・スキル特化・モジュール強化に必要な素材を集計します。
- **リージョン切替**: 大陸版（CN）／グローバル版（Global）を切り替え、未実装のオペレーター・ステージを編成対象から除外します。
- **編成共有**: 編成（ステージ＋最大12体＋メモ）を圧縮URL・QRコードで共有できます。
- **編成テンプレート**: プリセット／カスタムの編成テンプレートを保存・読込できます。
- **ステージメモ**: ステージごとに攻略メモを LocalStorage に保存できます（簡易Markdown対応）。
- **データベース閲覧**: オペレーター／ステージのマスターデータを一覧・検索・詳細表示します。
- **インポート／エクスポート**: 手持ちデータを JSON で書き出し・読み込みできます。
- **多言語対応**: 日本語・简体中文・한국어・English の4言語を `data/i18n.json` で切り替えます。
- **テーマ切替**: ダーク（既定）／ライトのテーマを切り替えられます。
- **PWA／オフライン対応**: インストール可能で、Service Worker により静的アセットをキャッシュしオフラインでも動作します。

## 技術スタック

- **Vanilla JavaScript**（フレームワーク・ビルドツールなし）
- **ES Modules**（`type="module"` による標準モジュール分割）
- **LocalStorage**（ユーザーデータの永続化）
- **静的 JSON**（`data/` 配下を `fetch` で読み込み）
- **Service Worker**（`sw.js` によるオフラインキャッシュ、PWA）
- 実行時依存なし。配布は Node.js スクリプト（`scripts/build.mjs`）で `dist/` に集約

## 使い方

JSONマスターを `fetch` するため、HTMLファイルを直接開くのではなく、プロジェクトルートでローカルHTTPサーバーを起動してください。

```bash
npx http-server .
```

表示されたローカルURLをブラウザーで開きます。公開用ファイルは次で生成できます。

```bash
npm ci
npm run build   # dist/ に静的ファイル一式を出力
```

## データについて

`data/operators.json`、`data/stages.json` は読み取り専用マスターです。★5/★6 を含む56体（★6 43体・★5 13体）を登録し、主要オペレーターのスキル・素質・モジュール・ステータスを収録しています。詳細が未確認の項目は `dataStatus` で明示し、空配列や `null` のままにしています。ステージは本編0〜8章に加え、殲滅作戦・危機契約・イベントステージを含む43件を収録しています。空配列を「該当なし」と解釈せず、出典と確認状況を合わせて確認してください。ゲームバージョンはPRTS Wikiの版一覧で確認したCN 2.7.71（2026-09-29公開）を記録しています。リージョンごとの実装状況は `data/regions.json`、スコアの重みは `data/scoring-config.json` に分離しています。

## 構成

- `index.html`: SPAシェル、ビュー領域、meta/OGP、ES Module入口
- `css/`: 基礎、レイアウト、コンポーネント、レスポンシブ、素材、PWAスタイル
- `js/main.js`: データ読込と画面初期化
- `js/modules/`: データ、状態、画面、スコアリング等の機能モジュール
- `data/`: オペレーター・ステージ・スコア設定・素材・リージョン・テンプレート・i18nのJSON
- `assets/`: OGP画像・ファビコン・PWAアイコン
- `scripts/`: ビルドスクリプトとテスト
- `sw.js`: Service Worker（オフラインキャッシュ）
- `docs/`: 設計ガイド・設計書

## 注意

編成・育成スコアは候補比較の目安であり、唯一の正解や勝率を保証しません。データ出典や利用条件を確認し、第三者の文章・画像を無断転載しないでください。アプリはユーザーデータを外部送信しません。
